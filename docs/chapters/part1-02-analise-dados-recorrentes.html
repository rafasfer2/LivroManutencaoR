2.2 Elementos de Suporte e Tempos Operacionais

Os elementos de suporte consistem nos dados diretamente monitorados e coletados durante a produção (Kang et al., 2016). No contexto do transporte, os dados dos caminhões off-highway são obtidos via horímetros instalados no sistema de medição, denominados tempos operacionais.

Esses dados são classificados hierarquicamente em três níveis para fins de cálculo de indicadores.

2.2.1 Hierarquia dos Tempos

Nível 1: Dados Brutos (Apontamentos) É a base de dados, composta pelas categorias primárias de horas registradas:

  • HEF: Horas Efetivas
  • HAO: Horas de Atraso Operacional
  • HTD: Horas Trabalhadas Diversas
  • HTI: Horas Trabalhadas de Infraestrutura
  • HOI: Horas Ociosas Internas
  • HOE: Horas Ociosas Externas
  • HMC: Horas de Manutenção Corretiva
  • HAC: Horas de Acidente
  • MPS: Horas Preventivas Sistemáticas
  • MPNS: Horas Preventivas Não Sistemáticas

Nível 2: Síntese de Categorias Para o cálculo de indicadores intermediários, realiza-se o agrupamento das horas do primeiro nível:

  • Manutenção Corretiva Total (\(H_{mct}\)): Soma das corretivas e acidentes (\(HMC + HAC\)).
  • Manutenção Preventiva (\(H_{mp}\)): Soma das preventivas sistemáticas e não sistemáticas (\(MPS + MPNS\)).
  • Trabalhadas Não Produtivas (\(H_{tnp}\)): Atividades de apoio e infraestrutura (\(HTD + HTI\)).
  • Ociosas (\(H_{oci}\)): Soma das ociosidades internas e externas (\(HOI + HOE\)).
  • Trabalhadas Produtivas (\(H_{tp}\)): Tempo efetivo de produção e atrasos operacionais inerentes (\(HEF + HAO\)).

Nível 3: Categorias Globais O nível mais alto de agregação, utilizado para KPIs estratégicos como Disponibilidade Física e Utilização:

  1. Horas Trabalhadas (\(H_{trab}\)): \(H_{tp} + H_{tnp}\)
  2. Horas em Manutenção (\(H_{man}\)): \(H_{mct} + H_{mp}\)
  3. Horas Paradas/Ociosas (\(H_{par}\)): \(H_{oci}\)
NotaEquação de Balanço

Em todos os níveis hierárquicos apresentados acima, a soma das categorias deve totalizar as Horas Calendário (\(H_{cal}\)). A relação fundamental para o terceiro nível é:

\[ H_{cal} = H_{trab} + H_{man} + H_{par} \]

2.3 Indicadores Chave de Desempenho (ICD)

Ao agrupar as categorias de horas em períodos, obtém-se a base para os indicadores. O principal produto do ciclo de transporte é a Massa Transportada (MT), que configura-se como o elemento quantitativo central.

De acordo com Kang et al. (2016), há dois tipos básicos de relacionamento entre indicadores:

  1. Identidade: Baseada nas definições matemáticas diretas.
  2. Relevância: Baseada em elementos de suporte compartilhados.

A Figura 2.2 apresenta um exemplo prático dessas conexões nos dados reais, mostrando como os status dos equipamentos alimentam as categorias de horas.

2.3.1 Definição Matemática dos Indicadores

Cada ICD revela um aspecto de desempenho para uma unidade de trabalho:

2.3.1.1 1. Disponibilidade Física (DF)

Indica a capacidade do sistema estar em condições de executar sua função. Sua indisponibilidade é causada pelas horas de manutenção (\(H_{man}\)). Este indicador aponta para oportunidades de melhoria na equipe de manutenção.

\[ DF = \frac{H_{cal} - H_{man}}{H_{cal}} \times 100\% = \frac{HD}{H_{cal}} \times 100\% \]

2.3.1.2 2. Utilização Física (UF)

Indica o quanto da disponibilidade (\(HD\)) é utilizada efetivamente para operação (\(H_{trab}\)). O tempo não utilizado corresponde à ociosidade (falta de operador, falta de frente de lavra, etc.). Este indicador reflete a eficiência da equipe de operação.

\[ UF = \frac{H_{trab}}{HD} \times 100\% \]

2.3.1.3 3. Produtividade (PR)

É o resultado da massa total transportada (\(MT\)) dividida pelas horas trabalhadas. Reflete a eficiência do ciclo de carregamento e transporte (velocidade, fator de enchimento, etc.).

\[ PR = \frac{MT}{H_{trab}} \quad (\text{t/h}) \]

2.4 Cálculo de Perdas de Produção

Quando um sistema produtivo não cumpre as metas, é fundamental calcular a perda de produção (em toneladas) atribuída a cada indicador. Isso permite criar “Gráficos de Cachoeira” (Waterfalls) para justificar os desvios de produção.

As equações baseadas na análise de variância (Realizado vs. Programado) são descritas abaixo. Considere os sufixos \(_prog\) para programado e \(_real\) para realizado.

1. Perda por Disponibilidade (\(PP_{DF}\)) Quanto se deixou de produzir porque o equipamento quebrou mais do que o planejado (redução de \(HD\)).

\[ PP_{DF} = (HD_{prog} - HD_{real}) \times PR_{real} \tag{2.1}\]

2. Perda por Utilização (\(PP_{UF}\)) Quanto se deixou de produzir porque o equipamento ficou ocioso mais do que o planejado (aumento de \(H_{oci}\)).

\[ PP_{UF} = (H_{oci\_real} - H_{oci\_prog}) \times PR_{prog} \tag{2.2}\]

3. Perda por Produtividade (\(PP_{PR}\)) Quanto se deixou de produzir porque o ritmo da operação foi menor que a meta (redução de \(PR\)).

\[ PP_{PR} = (PR_{prog} - PR_{real}) \times H_{trab\_real} \tag{2.3}\]

2.4.1 Exemplo Prático em R

O código abaixo demonstra o cálculo desses indicadores e das perdas associadas a partir de um conjunto de dados hipotético.

Código 
library(dplyr)
library(kableExtra)

# 1. Dados de Entrada (Simulação Programado vs Realizado)
dados <- data.frame(
    Indicador = c(
        "Horas Calendário (HC)", "Horas Manutenção (HM)",
        "Horas Disponíveis (HD)", "Horas Ociosas (HO)",
        "Horas Trabalhadas (HT)", "Massa Transportada (MT)"
    ),
    Programado = c(720, 72, 648, 65, 583, 140000),
    Realizado = c(720, 95, 625, 88, 537, 125000),
    Unidade = c("h", "h", "h", "h", "h", "t")
)

# 2. Cálculo dos ICDs Percentuais (Para visualização)
icds <- data.frame(
    Indicador = c(
        "Disponibilidade Física (DF)",
        "Utilização Física (UF)",
        "Produtividade (PR)"
    ),
    Programado = c(
        round((648 / 720) * 100, 1),
        round((583 / 648) * 100, 1),
        round(140000 / 583, 1)
    ),
    Realizado = c(
        round((625 / 720) * 100, 1),
        round((537 / 625) * 100, 1),
        round(125000 / 537, 1)
    ),
    Unidade = c("%", "%", "t/h")
)

# 3. Cálculo das Perdas (Variância / Waterfall)
# Definição de variaveis auxiliares para facilitar o cálculo
HD_prog <- 648
HD_real <- 625
HO_prog <- 65
HO_real <- 88
HT_real <- 537
PR_prog <- 140000 / 583
PR_real <- 125000 / 537

perdas <- data.frame(
    Tipo_Perda = c(
        "Perda por DF (Manutenção)",
        "Perda por UF (Operação/Ociosidade)",
        "Perda por PR (Ritmo/Ciclo)"
    ),
    Formula_Logica = c(
        "(HD_prog - HD_real) * PR_real",
        "(HO_real - HO_prog) * PR_prog",
        "(PR_prog - PR_real) * HT_real"
    ),
    Perda_ton = c(
        round((HD_prog - HD_real) * PR_real, 0),
        round((HO_real - HO_prog) * PR_prog, 0),
        round((PR_prog - PR_real) * HT_real, 0)
    )
)

# 4. Exibição das Tabelas Formatadas
# Tabela de Dados
k1 <- kable(dados, caption = "Tabela 1: Dados Programados vs Realizados") %>%
    kable_styling(bootstrap_options = c("striped", "hover"), full_width = FALSE)

# Tabela de Indicadores
k2 <- kable(icds, caption = "Tabela 2: Indicadores de Desempenho Calculados") %>%
    kable_styling(bootstrap_options = c("striped", "hover"), full_width = FALSE)

# Tabela de Perdas
k3 <- kable(perdas,
    caption = "Tabela 3: Análise de Perda de Produção (Waterfall)",
    col.names = c("Ofensor", "Lógica de Cálculo", "Perda (t)")
) %>%
    kable_styling(bootstrap_options = c("striped", "hover"), full_width = FALSE) %>%
    row_spec(which(perdas$Perda_ton == max(perdas$Perda_ton)), bold = T, color = "red")

# Imprimir tabelas (no Quarto, elas aparecem sequencialmente)
k1
