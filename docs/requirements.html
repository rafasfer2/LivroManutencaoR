Convenções e Organização

Este livro foi desenvolvido para ser prático, reproduzível e didático. Todos os exemplos de código R podem ser executados diretamente, e os dados utilizados estão disponíveis no diretório resources/data/.

Organização dos Capítulos

O livro está dividido em quatro partes principais:

  1. Fundamentos e Teoria — Conceitos básicos de confiabilidade, distribuições de vida útil e métodos de estimação.
  2. Análise e Modelagem Prática — Técnicas de análise de dados de falha, modelagem Weibull e análise de sobrevivência.
  3. Estratégias de Manutenção — Manutenção preventiva, preditiva e modelagem de sistemas complexos.
  4. Métodos Avançados e Aplicações — Simulação Monte Carlo, estudos de caso industriais e governança de dados.

Cada capítulo inclui:

  • Teoria concisa — Explicação dos conceitos fundamentais.
  • Exemplos práticos com R — Código reproduzível e comentado.
  • Visualizações e tabelas — Gráficos interpretativos e resumos estatísticos.
  • Exercícios 📝 — Atividades para consolidar o aprendizado.

Equação de confiabilidade (definição usada ao longo do livro):

$$
R(t) = e^{-\lambda t}
$$ {#eq-confiabilidade}

```{r}
#| label: fig-weibull
#| fig-cap: "Distribuição Weibull ajustada aos tempos de falha de equipamentos"
#| echo: false
#| warning: false
#| message: false

library(ggplot2)
library(dplyr)
library(fitdistrplus)

# Carregar dados de falhas
data <- read.csv("resources/data/falhas.csv")

# Filtrar apenas falhas completas (não censuradas)
falhas <- data %>%
  filter(censura == 0) %>%
  pull(tempo_ate_falha)

# Ajustar distribuição Weibull
fit_weibull <- fitdist(falhas, "weibull")
shape_est <- fit_weibull$estimate["shape"]
scale_est <- fit_weibull$estimate["scale"]

# Criar dataframe para plot
df <- tibble(tempo = falhas)

# Histograma com curva Weibull ajustada
ggplot(df, aes(x = tempo)) +
  geom_histogram(aes(y = after_stat(density)), bins = 20,
                 fill = "#2E86C1", alpha = 0.6, color = "white") +
  stat_function(fun = dweibull,
                args = list(shape = shape_est, scale = scale_est),
                color = "#E74C3C", linewidth = 1.2) +
  labs(x = "Tempo até falha (horas)",
       y = "Densidade",
       subtitle = sprintf("Parâmetros: β = %.2f, η = %.0f", shape_est, scale_est)) +
  theme_minimal(base_size = 12) +
  theme(plot.subtitle = element_text(color = "#E74C3C", face = "italic"))
```

```{r}
#| label: tbl-mtbf
#| tbl-cap: "Cálculo de MTBF por tipo de equipamento"
#| echo: false
#| warning: false
#| message: false

library(dplyr)

# Carregar dados
data <- read.csv("resources/data/falhas.csv")

# Calcular MTBF por ativo (apenas falhas completas)
mtbf_summary <- data %>%
    filter(censura == 0) %>%
    mutate(tipo = sub("_.*", "", ativo)) %>%
    group_by(tipo) %>%
    summarise(
        n_falhas = n(),
        tempo_total = sum(tempo_ate_falha),
        mtbf = round(tempo_total / n_falhas, 1),
        .groups = "drop"
    )

mtbf_summary %>%
    dplyr::select(tipo, n_falhas, mtbf) %>%
    knitr::kable(
        format = "html",
        col.names = c("Tipo de Equipamento", "Nº de Falhas", "MTBF (horas)"),
        align = c("l", "c", "c")
    )
```
